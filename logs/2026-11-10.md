学习内容：Shell基础和Vim基础编辑模式

1.参数解析

我理解：将用户输入的字符串按空白字符分割，每个由空白字符分割的单词就是一个参数

注意：用引号可以输出包含空白字符的参数

自己测试的命令：echo hello world

echo "hello       world"

echo hello      world



2.手册

我理解：系统自带的命令说明书

测试的命令：man echo

注意：Windows cmd：命令 /?，只是简短提示；

PowerShell：help 命令；

Linux bash：man 命令。

**在命令后加上-help能获取该命令的简短说明**



3.常用命令:

&#x20;1.ls list，列出当前目录文件

ls -l   # 详细信息（权限、大小、时间）

ls -a   # 显示隐藏文件



&#x20;2.cd,切换目录

cd \~        # 回到家目录

cd ..       # 上一级目录

eg：cd learning-log



&#x20;3.pwd print working directory，查看当前完整路径

pwd



4\.cat 读取文件内容并输出到屏幕

bash

eg：cat test.txt



5\.echo 输出文字

eg：echo hello

echo "abc" > test.txt   # 重定向写入文件



6\.mkdir make directory，新建文件夹

mkdir testdir



7\.rm remove，删除文件 / 文件夹

eg：rm test.txt

rm -r testdir  # 删除文件夹（递归）

⚠️ rm 删除没有回收站，谨慎使用



8\.cp copy，复制

eg：cp a.txt b.txt



9\.mv move，移动 / 重命名

eg：mv a.txt newa.txt



10\.man 查看命令手册

eg：man ls



11\.grep 过滤匹配文本（管道高频搭档）

eg：ls | grep txt



12\.history 查看你敲过的历史命令

history



13.find 在目录里搜索文件 / 文件夹，按名字、大小、时间等条件查找，遍历子目录

命令：find 搜索路径 -条件

eg：find . -name "\*log\*"   在当前目录找名字含 log 的文件



14.sed

全称：stream editor 流编辑器。

作用：按行处理文本，最常用用来替换字符串，也是管道链里很常用的工具。

eg： sed 's/旧内容/新内容/g' 文件名

s = substitute 替换

/ 是分隔符

g = global，一行里面全部匹配都替换；不加 g，只替换每行第一个匹配







$? 查看上一条命令退出码

eg：

echo $?





&#x20;4.Tab键

我理解：Shell 中 Tab 默认是补全快捷键，自动补全文件名、目录名、命令名；

注意：若结果可能有多种，则可输入两次Tab获得所有可能结果；

在Shell中输入制表符\\t, Ctrl+V +Tab



5.grep

我理解：文本过滤工具，找出文本里包含指定关键字的行

测试的命令：grep "关键词" 文件名





&#x20;6.管道 |

我理解：把前一个命令的标准输出 stdout，直接交给后一个命令，当作它的标准输入 stdin。

自己测试的命令：ls | grep txt

ls 输出列表 → 通过管道传给 grep → grep 筛选带 txt 的行



7. 重定向 > >> <

我理解：数据输入输出的指定方向，不只局限于键盘和终端

0  stdin  标准输入

1  stdout 标准输出

2  stderr 标准错误



>   1>  覆盖输出到文件

>>  1>> 追加输出到文件

2>      错误输出写入文件

2>>     错误输出追加到文件

\&>      输出+错误 一起写入文件

<       把文件作为输入传给命令



8. Shell变量

我理解：Shell 里用来存放数据的容器，自定义变量直接赋值；系统自带环境变量（如 PATH、SHELL），用$变量名读取里面的值。

自己测试的命令：name="test"

echo $name

echo $PATH

遇到的问题：赋值的时候等号两边不能加空格，加空格会报错。



9. 退出码 $?

我理解：上一条命令执行结束后的返回值，用来判断命令成功还是失败。0 代表执行成功，非 0 代表出错。

自己测试的命令：ls

echo $?

ls notexistfile

echo $?

遇到的问题：$?只会保存最近一条命令的退出码，再跑一条命令就会覆盖掉原来的值。



10.vim编辑模式

我理解：Vim 是模式编辑器，区分普通模式、插入模式；依靠键盘快捷键完成光标移动、增删复制粘贴、搜索、保存退出，全程不用鼠标。

自己测试的命令：vimtutor，练习 hjkl i a o dd yy p u / :wq

令。

遇到的问题：不小心停在插入模式，很多命令失效，记住 ESC 回到普通模式才能执行命



前提：默认是普通模式（Normal），按 ESC 回到普通模式

h 光标左

j 光标下

k 光标上

l 光标右

i 在光标前面进入插入模式

a 在光标后面进入插入模式

o 在下新开一行，进入插入

dd 删除整行

yy 复制（yank）整行

p 粘贴（粘贴到光标后面）

u 撤销上一步操作

/ 搜索，输入关键词回车查找；n跳到下一个匹配

:wq 保存并退出 vim
